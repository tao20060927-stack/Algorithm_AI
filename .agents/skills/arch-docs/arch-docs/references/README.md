# References

| Script | Content |
|--------|---------|

| `scripts/load-checklists.sh` | Security, operability, testing checklists |

Template types: `hld`, `lld`, `risk`, `decision`, `tab-pack`, `tab-slides`, `evidence`, `peer-review`
